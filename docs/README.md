# Design Documents

This directory collects design notes and reference material for the project. Use it to capture architecture decisions and future plans rather than source code or tooling scripts. The telemetry journal is a kernel-internal mechanism; userland observes the system through graph queries and watches rather than raw journal access.

## Documents
- **TELEMETRY_GRAPH_API.md** – outlines the Thing-based telemetry graph model and API usage patterns.
- **THINGOS_VISION.md** – summarizes the long-term goals and guiding principles for the OS.
